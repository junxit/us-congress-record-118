# Vote on Falk Nomination (Executive Session)

**Speaking:** Hassan, Margaret Wood (H001076) [D-NH], Durbin, Richard J. (D000563) [D-IL], Thune, John (T000250) [R-SD]

```
                        Vote on Falk Nomination

  Ms. HASSAN. Mr. President, I request consent for the scheduled vote 
to start immediately.
  The PRESIDING OFFICER. Without objection, it is so ordered.
  The question is, Will the Senate advise and consent to the Falk 
nomination?
  Ms. HASSAN. I ask for the yeas and nays.
  The PRESIDING OFFICER. Is there a sufficient second?
  There appears to be a sufficient second.
  The clerk will call the roll.
  The legislative clerk called the roll.
  Mr. DURBIN. I announce that the Senator from Vermont (Mr. Sanders) is 
necessarily absent.
  Mr. THUNE. The following Senators are necessarily absent: the Senator 
from Alaska (Ms. Murkowski) and the Senator from Florida (Mr. Rubio).
  The result was announced--yeas 60, nays 37, as follows:
```
