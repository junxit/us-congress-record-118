# Border Security (Executive Session)

**Speaking:** Wyden, Ron (W000779) [D-OR], Thune, John (T000250) [R-SD]

```
                            Border Security

  Mr. President, now we should turn to addressing another important 
aspect of our national security in a bipartisan fashion, and that is 
securing our border. The kind of unchecked illegal immigration we are 
currently experiencing at our southern border represents a serious 
national security threat--one that so far Democrats are refusing to 
meaningfully address. I hope that their position will shift in the 
coming days and that we will be able to work together to pass a 
supplemental bill which not only provides support for our allies but 
which also contains real measures to secure our border. The NDAA should 
not be the only national security legislation that we pass this 
December.
  I yield the floor.
  I suggest the absence of a quorum.
  The PRESIDING OFFICER. The clerk will call the roll.
  The legislative clerk proceeded to call the roll.
  Mr. WYDEN. Mr. President, I ask unanimous consent that the order for 
the quorum call be rescinded.
  The PRESIDING OFFICER. Without objection, it is so ordered.
```
