# MEASURE READ THE FIRST TIME--S. 299

**Speaking:** Kaine, Tim (K000384) [D-VA]

**Measures:** S. 299

```
                  MEASURE READ THE FIRST TIME--S. 299

  Mr. KAINE. Mr. President, I understand there is a bill at the desk, 
and I ask for the first reading.
  The PRESIDING OFFICER. The clerk will read the bill by title for the 
first time.
  The senior assistant legislative clerk read as follows:

       A bill (S. 299) to amend title 31, United States Code, to 
     provide for automatic continuing resolutions.

  Mr. KAINE. I now ask for a second reading, and in order to place the 
bill on the calendar under the provisions of rule XIV, I object to my 
own request.
  The PRESIDING OFFICER. Objection is heard.
  The bill will be read for the second time on the next legislative 
day.
```
