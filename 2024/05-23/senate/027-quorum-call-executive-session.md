# Quorum Call (Executive Session)

**Speaking:** Schumer, Charles E. (S000148) [D-NY]

```
                              Quorum Call

  The PRESIDING OFFICER. Pursuant to rule XXII, the Chair now directs 
the clerk to call the roll to ascertain the presence of a quorum.
  Mr. SCHUMER. Madam President, I ask unanimous consent to waive the 
quorum call.

[[Page S3878]]

  The PRESIDING OFFICER. Is there an objection?
  Without objection, it is so ordered.


 =========================== NOTE =========================== 

  
  On page S3878, May 23, 2024, in the left column, the following 
appeared: The PRESIDING OFFICER. Is there an objection? Without 
objection, it is so ordered. Is there a quorum? A quorum is 
present.
  
  The online Record has been corrected to read: The PRESIDING 
OFFICER. Is there an objection? Without objection, it is so 
ordered.
```
