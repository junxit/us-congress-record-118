# MEASURE READ THE FIRST TIME--H.R. 6914

**Speaking:** Smith, Tina (S001203) [D-MN]

**Measures:** H.R. 6914

```
                 MEASURE READ THE FIRST TIME--H.R. 6914

  Ms. SMITH. I understand there is a bill at the desk, and I ask for 
its first reading.
  The PRESIDING OFFICER. The clerk will read the bill by title for the 
first time.
  The senior assistant legislative clerk read as follows:

       A bill (H.R. 6914) to require institutions of higher

     other purposes.
```
